# 19. 更新核心

- **内核自动更新**：安装后自动挂 cron，**每月北京时间 2 号凌晨 04:00**（服务器在任何时区都自动换算，夏令时也对） 把 sing-box / xray 更新到最新并重启一次
  （无新版则跳过）；也可随时进管理面板 **19 更新核心** 手动立即更新。日志在 `/var/log/bgpeer-coreupdate.log`
- **凌晨任务排队**：内核更新（每月 2 号 04:00）、屏蔽规则刷新（每天 03:00）、nginx 升级（每月 1 号 03:10）、三大配置自动更新（每天 03:20），以及 Emby 那套的刷新元数据（默认 03:30）、自动更新脚本（04:10）、每日对齐（04:50）都先交给排队器 `bgpeer-jobq`（Emby 04:15 刷目录缓存要赶 04:20 生成 strm，不排；保活、预热这些每小时 / 每分钟的轻活也不排）：**一个跑完再跑下一个**，前面的没跑完后面的就等着；队列记在硬盘上，**服务器中途重启，被打断的和还没轮到的开机后自动接着跑**（登记超过 12 小时的不再补跑；单个任务最长 4 小时）。看队列 `bgpeer-jobq list`，日志 `/var/log/bgpeer-jobq.log`
- **更新核心不怕 SSH 断**：更新的最后一步是重启核心，而很多人是**挂着本机代理管理这台机**的，重启会当场掐断 SSH。
  菜单 19 会把更新**派到独立会话里执行**（脱离控制终端，SIGHUP 打不到它），断开后仍在服务端跑完；前台只是实时跟随
  日志给你看进度，随时 Ctrl-C 或直接断开都不影响。重连后 `tail /var/log/bgpeer-coreupdate.log` 看结果

- **两个核心的取版本策略不同**（不是笔误，是刻意的）：**xray** 取全部 release 里**版本号最大的那个，包含被标为
  「预发行」的**——XTLS 从 `v26.6.1` 起把每个 release 都标成了预发行，而 GitHub 的 `/releases/latest` 按定义只返回
  非预发行版，只认它会**永远停在 `v26.3.27`**、每月的自动更新也推不动。注意预发行是 release 上的独立标志位、跟 tag
  名无关（xray 的 tag 一律是 `v26.7.28` 这种纯版本号，看 tag 名分辨不出来）。**sing-box** 则仍只认 `/releases/latest`
  的正式版：它 `1.13` 正式线和 `1.14.0-beta` 线**并行维护**，而 `1.14.0-beta.7` 的版本号大于 `1.13.16`，取最大会把人
  送上 beta 线、跨小版本换配置 schema，节点可能直接起不来
- **xray reality 的最低客户端版本**：xray 从 v26.7.11 起，reality 服务端**默认 `minClientVer=26.3.27`**，会
  **静默拒掉上报旧版本的客户端**（mihomo/Clash 系内核固定上报 `1.8.2`）——表现为升级 xray 后 reality 节点客户端
  **连不上、也不报错**（全被丢进 fallback）。本脚本给 xray reality 入站显式写 `minClientVer`：早先写 `1.0.0`，
  现在跟 mack-a 一样写 **`1.8.2`**（mihomo 正好放行，xray 客户端报的是自己的版本号）。**新装**即带；**老装**在「更新核心」
  或下次打开面板时**一次性改成 1.8.2**，借用目标站够格的同一趟**开上抗量子签名**、链接补 `pqv=`、订阅重建，然后重启 xray
  （见[安装篇](01-install.md#伪装--加密建议)）。之后不再动。sing-box 内核没有这个选项、不受影响。
- **sing-box 1.14.0 ~ 1.14.2 的 httpupgrade 偶发断连（1.14.3 已修）**：服务端回完 `101` 再接管连接时，把 Go HTTP
  服务器已经读进缓冲的字节扔了——客户端数据来得快，vmess 头就少了第一个字节，服务端日志报
  `inbound/vmess[…vmess-httpupgrade]: process connection …: bad request`，这条连接断掉、客户端那次请求失败。
  本机实测（客户端和服务端在同一台、延迟近乎为 0）1.14.0 约 1%（2000 次 23 次），1.14.3 为 0；隔着公网延迟大，
  很难碰上。**节点配置没问题，跑一次 19 更新核心升到 1.14.3 或更新的就没了**（每月 2 号的自动更新也会升上去）。
