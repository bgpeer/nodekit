# 5. 提速：多路复用 smux / hy2 满速

菜单里两项，互不相干、各自开关：`1` smux 开关（ws 类），`2` hy2 满速（Brutal）。

## 1. 多路复用 smux

装好后随时开/关 smux，不用重装、不动节点。菜单里 `1` 循环切换（显示当前状态，
`y` 确认 / `n` 返回）。执行后自动:改 sing-box ws 入站的 `multiplex` → 同步分享链接
标记 → 重启 sing-box → 刷新三格式订阅（token/URL 不变）。改完客户端重新拉订阅，
或到各配置菜单点 **3 更新配置** 即可生效。只影响 ws/httpupgrade 类 sing-box 节点，
xray 承载的 ws、reality/vision/QUIC 等一概不动。

## 2. hy2 满速（Brutal）

hy2 默认不填带宽，用的是 BBR：一边探一边发，一丢包就收。出国线路丢包多，**上传**（手机 → VPS）尤其吃亏——
比如往电报传视频。开了满速就是 Brutal：按你填的速度一直发，丢包也不减速。

- 填**宽带套餐的下行 / 上行**（Mbps）。回车两下 = 下行 1000 / 上行 100（千兆宽带常见值），`0` = 关、回到自动。
- 改完三大配置自动刷新（订阅地址不变），客户端刷新一次订阅就生效。只写进客户端配置：mihomo 的 `up` / `down`、
  sing-box 的 `up_mbps` / `down_mbps`；服务端不用动。小火箭的 hy2 不认这两个参数，不受影响。
- **数别填得比宽带还大**：线路就那么粗，填大了不会更快，多出来的包在半路丢掉——下载方向是 VPS 往外发，丢掉的
  也算 VPS 流量（比如实际只能跑 300 兆、填 1000，下 1 GB 要扣三四 GB 流量）；Hysteria 官方文档也说设高了丢包严重、
  反而变慢。
- 默认关：每个人的宽带不一样，默认开会让慢线路更慢、更费流量。
