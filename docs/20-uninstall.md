# 20. 卸载

管理面板选 **20. 卸载**，进子菜单（每项后面显示装没装）：

```
  1. 卸载代理主体　当前：已安装
  2. 卸载网络优化　当前：已启用
  3. 卸载自建DNS　当前：已安装
  4. 卸载自建Emby　当前：未安装
  5. 全部卸载
  0. 返回
```

1~4 各卸各的，卸完一项回到这一屏看状态；没装的那项直接说「不用卸」。

- **1 代理主体**：sing-box / xray、订阅服务、节点证书（acme.sh 里那条一起撤，不再续期）、CDN 套用节点、
  hy2 端口跳跃规则、nginx 前置块、cn-block / 内核更新等定时任务。
  - 网络优化、自建DNS、Emby 是独立模块，**不跟着卸**；它们还在的话 `bgpeer` 命令和 `/etc/bgpeer` 留着
    （只删节点自己的文件），以后还能回这里卸它们。
  - 老装法的自建DNS（跟节点共用 `/etc/ssl/sb` 那张证书）证书一删就起不来，会走它自己的卸载一起撤干净，确认前屏上会写明。
  - Emby 的网站正用着节点证书时，`/etc/ssl/sb` 留着。
- **2 网络优化**：跑 `net-optimize.py --reset`，内核参数 / 服务 / 防火墙标记全部还原，节点不受影响。
  换过的 BBRv3 内核（XanMod）**留着**——换回系统内核选 5，或 `12 → 4 → 2`。
- **3 自建DNS**：AdGuard Home 自己的卸载（列清单、再问一次）：服务、证书、CF 令牌（没别人用时）、ufw 规则、
  本机解析、订阅里的 DoH 一起撤。
- **4 自建Emby**：media-stack 自己的卸载（要打 yes，再问删不删数据目录）。
- **5 全部卸载**：屏上一行红字「将卸载脚本所有功能包括系统内核回到初始状态，请考虑清楚再执行」，
  **必须输入 `yes`** 才执行（`y` 和回车都是取消）。依次：
  1. Emby（连数据目录一起删）
  2. 自建DNS
  3. BBRv3 内核换回系统内核（/boot 里没有系统内核可回就不卸）
  4. 网络优化
  5. 代理主体 + `bgpeer` 面板 + `/etc/bgpeer`

  最后把 acme.sh 里本脚本签的证书撤掉；acme.sh 只给本脚本签过证书就连它一起卸（CF 令牌随之删掉），
  还有你自己网站的证书就留着它。换了内核 / 还原了内核参数的，问一次要不要现在重启（默认否）。
- 系统本身、SSH、nginx / docker 这些软件包、你自己的其它网站一概不动。
