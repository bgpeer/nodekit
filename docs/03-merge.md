# 3. 聚合节点链接

有 2~3 台 VPS 都装了节点，想把它们**汇总成一条订阅**、免去手动复制粘贴：

1. **每台机器**进「3 聚合节点链接」，**顶部**就显示这台自己的**节点链接地址**（`.links` 结尾，token 保护）；
2. 选一台当**主机**，进「3 聚合节点链接」→ `1 添加链接`，把其它机器顶部的那条 `.links` 地址粘进来；
   列表里每条后面实时显示连通性：通了 `✓`、不通显示红色状态码（`404`/`不通`）；
3. 主机进任意配置菜单点 **更新配置** → 自动拉本机 + 各成员机全部节点、去重、套模板、
   国家随机分组**跨机归类**，生成**一条聚合订阅**。客户端只导入主机这一条即可。

- 增删链接自动重排序号；**删除支持多选**（逗号分隔如 `1,3`、或 `a` 全部）；生成时**拉不到的成员自动忽略**（不影响其它机器）。
- **同名自动区分**：两台用相同前缀+相同协议时节点会重名（如两台都 `🇯🇵vless-vision`），
  mihomo/sing-box 不许重名，聚合时**只给撞名的加小上标** `¹²³`（→ `¹🇯🇵vless-vision`、
  `²🇯🇵vless-vision`），没撞的保持原样；旗子还在，国家随机分组照常归类。
- **links 链接可刷新（防泄露）**：`.links` 地址带 token，泄露了别人能直接拉你的节点。
  菜单里 `3 刷新本机 links 链接` 可随时换 token、旧地址立即失效；**重装换节点也会一起换**
  （和订阅一样）。换过之后，聚合了本机的主机会显示红色 `404`，重新复制新地址粘一次即可。
- 聚合后会把**各 VPS 都写进「直连」规则**（**有域名的用域名、没域名的用 IP**，配置里不落地裸 IP），
  你挂着聚合代理管理任意一台，管理流量都走直连不断线。<br>
  ⚠️ 用域名时直连规则匹配的是**域名**，所以挂着代理管理请 **SSH 到域名**（`ssh root@你的域名`）才会命中直连；
  直接 SSH 到裸 IP 不走这条规则（想彻底不断线要么 SSH 域名、要么管理时关代理）。

> **关于「改配置会重启核心、可能掐断 SSH」**：安装、smux 开关、BT 屏蔽、屏蔽中国域名、
> 更新核心等操作都会重启 sing-box/xray；若你正挂着这台机器的代理来 SSH 管理，重启会掐断隧道。
> 脚本已经做了三重保护，**单台 VPS 也不会被锁死**：
> 1. **改配置先校验、坏了自动回滚**（`sing-box check` / `xray -test` 不过就还原、绝不重启），
>    所以一个坏配置永远不会把你唯一的回程路弄没；
> 2. **状态先落盘、再后台异步重启**（`--no-block`），即便 SSH 断了操作也已在服务端完成，重连即最新；
> 3. **订阅里自动加一条「本机 IP 直连」规则**（mihomo/sing-box/小火箭都注入），
>    这样你挂着本机代理时，SSH 到这台 VPS 走**直连不进代理**，重启核心根本不断你。
> 客户端拉一次新订阅即生效。仍嫌麻烦的话，直连管理（管理时关代理）最省事。
