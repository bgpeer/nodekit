# 21. EasyTier 组网

把几台 VPS 连成一个虚拟局域网（默认 `10.144.0.0/24`），互相用内网 IP 访问，服务不用再把
端口暴露到公网。EasyTier 是去中心化 mesh VPN：没有中心服务器，节点之间自己打洞直连，
打不通才走中继；加密默认开。同名同密钥 = 同一个网，不知道这两样进不来。

VPS 上不跑 mihomo（mihomo 在 nodekit 里只是生成给客户端的订阅格式），所以这里直接跑
`easytier-core`，不经过 mihomo 的 easytier 出站。手机 / 电脑上的 mihomo 客户端想进网，
用它自己的 easytier 出站配置，跟这台机器上的服务没关系。

- **`1 安装 EasyTier`** —— 拉最新版（取不到就用钉死的版本兜底），装 `easytier-core` 和
  `easytier-cli` 到 `/usr/local/bin`，装完校一遍版本号。已是最新版就跳过。
- **`2 配置组网`** —— 先选角色：
  - **首节点**：监听，等别人来连；内网 IP 默认 `10.144.0.1`。
  - **加入节点**：填首节点那台的公网 IP（端口固定 `11010`）；内网 IP 默认 `10.144.0.2`。
  - 网络名默认 `bgpeer-mesh`，密钥回车随机生成（也可以自己填，至少 8 位）。
  - 上次配过的当默认值，回车就沿用；密钥回车是「保持原样」，打 `random` 重新随机生成。
  - 配好起服务、开开机自启。配置存在 `/etc/bgpeer/easytier.conf`（0600，只有 root 能读），
    跟 AdGuard 的 `agh.password` 一个做法；服务读的是另外一份 `/etc/bgpeer/easytier.toml`
    （也是 0600），密钥只在文件里，不进服务文件、不进进程命令行。
- **`3 状态`** —— 服务状态、配好的网络名 / 角色 / 内网 IP / 密钥（印出来是故意的：
  配另一台机器要照着抄），再加 `easytier-cli peer` 的对端表。
- **`4 开机自启`** —— 开 / 关切换。
- **`5 卸载 EasyTier`** —— 服务停掉，二进制、配置和密钥一起删，内网就断了；默认否。

> 首节点要在**云防火墙放行 TCP 11010**，不然别人连不进来——这一步脚本够不着厂商面板，
> 菜单里会提醒。配好之前别急着关公网端口，先确认内网能访问了再动。

> 菜单 20 的「5 全部卸载」暂不含 EasyTier（那边的 1/5～5/5 排好了，动编号要连测试
> 一起改）：要卸在菜单 21 里自己卸。`easytier.py remove --yes` 已经留好了，
> 以后接过去就能用。
