# 2. 节点链接 / 订阅

> **mihomo 订阅里的值一律带引号**，看着啰嗦，但这是被真事咬过的。reality 的 `short-id` 是
> 8 位随机 hex，随机到 `38e92059` 这种「数字 e 数字」的形状时，按 **YAML 1.2** 的浮点规则
> 它是 38×10^92059 —— 远超双精度上限，解析出来直接是 `Infinity`；客户端接着把配置 JSON 化
> 就炸在这里（ClashMi 报 `Converting object to an encodable object failed: Infinity`）。
>
> 最难查的是各家解析器口径不一样，同一份配置有的客户端能用、有的不能：
>
> | 解析器 | 怎么读 `38e92059` | 结果 |
> |---|---|---|
> | Go / yaml.v3（mihomo 自己） | `ParseFloat` 溢出报错 → 回退成字符串 | 正常 |
> | PyYAML（YAML 1.1，浮点必须带小数点） | 当字符串 | 正常——**所以在服务端自测根本扫不出来** |
> | Dart / JS（YAML 1.2） | 浮点，溢出成 `Infinity` | 炸 |
>
> 所以渲染时不去判断「这个值像不像数字」（正是这种判断在各家 YAML 版本之间不一致），
> 反过来做白名单：只有真数字和 `true`/`false` 裸写，其余一律双引号 + 转义。
> 随机生成的 short-id / 密码 / 路径再怎么撞形状，都不会被谁读成别的类型。
> 节点名里带引号或反斜杠也顺带一起转义对了。

装完为每种客户端各生成一条订阅链接（托管端口**每台机器首装时随机分配**——固定端口所有人一样
容易被按端口批量扫描识别，随机后和协议端口混在一起。平时换 token、更新脚本/配置端口都不动、
订阅 URL 稳定；**只有重装换节点时端口才随 token 一起换新**。升级上来的老安装沿用原端口，
订阅链接不变）：

| 客户端 | 格式 |
|--------|------|
| mihomo / Clash | `.yaml` |
| sing-box | `.json` |
| Shadowrocket（小火箭）| `.conf`，**一个链接**：规则、分组、节点都在里面（见[小火箭：一个链接](06-08-client-config.md#小火箭一个链接)） |

**订阅走 HTTPS**：有域名 + acme 真证书时，订阅托管服务自动用真证书起 **HTTPS**
（`https://你的域名:订阅端口/...`），订阅内容不再明文过网。证书续期时订阅服务同步重启、
不会拿旧证书。**无域名 / 自签**时仍是明文 HTTP（自签 TLS 客户端会拒，故不强开）——
想要 HTTPS 订阅就给个域名。

每种格式的配置模板都在本仓库里，节点参数由服务端实时注入到模板锚点，重装换节点也会自动更新。
详见「6 / 7 / 8」那一页的 [自定义模板 & 锚点](06-08-client-config.md#自定义模板--锚点)。

**每条订阅标题后面标着它用的模板**：`（作者模板）` 或 `（自定义模板）`（自定义的换个颜色；小火箭改成节点订阅时多出来的那条 `.txt` 没有模板，不标）。
三个格式各记各的，在「6 / 7 / 8 → 3 更新配置」里选过哪套就是哪套；刷新、每天 03:20 自动更新都按它。

## 云防火墙要放行的端口

单节点链接和订阅之间有一段「云防火墙要放行的端口（tcp、udp 两栏都填）」，装完、「只添加新协议」之后也有：

```
[本机 🇺🇸OR]
80,443,18047,19286,29235,31000-32000,36844
```

- **本机**：两个核心对外监听的节点端口、订阅端口、伪装站的 80 / 443、CDN 回源端口、hy2 端口跳跃段。挂在 nginx 后面、
  只在本机内部用的端口不列；落在跳跃段里的单端口不重复列。
- **只列本机**。聚合的成员机不列：它们的端口到那台自己的「2 节点链接」里看。
- 端口那行顶格、不上色，长按复制，GCP / AWS 这类云厂商的防火墙 tcp、udp 两栏各粘一次。本机的 ufw / firewalld 脚本会自己放行，
  云厂商控制台里的管不到——少放行一个，那个节点就一直不通（服务器上看一切正常）。

**`2 刷新三大配置`**：三个格式各按上面标的模板重新生成一遍，一格式一行 ✔ / ⚠。
跟每天 03:20 自动更新是同一套：不动节点、不换 token、不重启任何服务，**订阅地址不变**，客户端刷新一次订阅就是新的；
生成或校验失败就保留原来那份。跟 03:20 不同的两处：自动更新关了的格式也刷（手动点的就是要刷）；
用「修改配置」**手改过**的格式，先红字说清会覆盖手改的内容、**默认不刷**，回 `y` 才覆盖。
