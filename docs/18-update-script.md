# 18. 更新脚本

面板标题栏会显示当前脚本版本（如 `bgpeer 一键脚本 v1.0.0`）。菜单：

```
更新脚本（不影响节点）
  当前版本：v1.1.130
  1. 立即更新
  2. 自动更新　当前：开（每天 02:50）
  0. 返回
```

- **`1 立即更新`**：拉最新版，显示 `v旧 → v新`，换上后自动重新载入新版面板。只换脚本本体，节点、配置都不动。
- **`2 自动更新`**：开 / 关切换，默认开。每天北京时间 02:50 自动检查一次，有新版就换上——不上服务器、不开面板的机器，
  修的 bug、加的功能也能用上。拉不到、版本没变新、新版文件不完整（语法过不了）都不换，照旧用原来的。
  只换脚本本体，不重启任何服务、不动节点；跟节点「自动更新配置」是两个独立开关，关了一个不影响另一个。
  日志：`/var/log/bgpeer-selfupdate.log`。

发布是全自动的：脚本/模板有改动**合并进 main 就算发布**——GitHub Actions 会自动把
`xy-installer.py` 里的 `SCRIPT_VERSION` 补丁位 +1（如 1.0.0 → 1.0.1）、打 `vX.Y.Z` 标签、
并在仓库 [Releases](https://github.com/bgpeer/nodekit/releases) 页创建发布（更新说明自动生成），
不需要手动操作。想升大版本（如 2.0.0），合并前手动把 `SCRIPT_VERSION` 改成目标版本号即可，
CI 检测到比已发布的高就直接用它，不再自动 +1。
