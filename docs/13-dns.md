# 13. 自建DNS

- **自建 DNS 的 DoH 地址带 ClientID**（形如 `https://域名:10443/dns-query/xy<随机>`）：AdGuard 的 DoH 挂在公网上，
  **不设白名单谁扫到都能拿去当免费解析器**。ClientID 不用先开「写入订阅」：AdGuard 菜单「3 使用方法」最上面
  「要填的就这几行」里就列着（安卓「专用DNS」主机名、DoH 地址、明文 DNS；签了泛域名证书后还有「允许的客户端」），用到时自动生成。
  把它填进 AdGuard 后台 **设置 → DNS 设置 → 访问设置 → 允许的客户端**，就只放行你自己。
  **先做菜单 8（签泛域名证书）再设白名单**：安卓专用 DNS 要把 ID 放进主机名（`ID.域名`）才带得上，没有泛域名证书时
  白名单一设，安卓专用 DNS 就被挡（「使用方法」最上面会红字直说，二选一：做菜单 8，或清空白名单）。手机流量 IP 天天变、没法按 IP 白名单，
  ClientID 与 IP 无关正合适。ID 存在 `/etc/bgpeer/selfdns.clientid`（root-only），不在托管目录、不会被下载。
  向后兼容：没配「允许的客户端」时 AdGuard 对任意 ClientID 都放行，所以带上它不会让原本能用的配置失效
- **自建 DNS 写入订阅时，mihomo 会写三处**（菜单 13 的开关打开时）：`nameserver`（默认解析）、`global-dns` 锚点
  （所有走代理的域名组共用）、`proxy-server-nameserver`（解析节点服务器域名）。三处都是**插到列表最前、
  原有条目留作兜底**——mihomo 对这些列表是并发查询、谁先回用谁，所以自建 DoH 通了就用它，**挂了只是输掉
  竞速**，不会硬故障。地址按你自己的域名动态生成，不写死在模板里；关掉开关时不插入即可，模板每次生成都是
  实时重新拉取的

在 VPS 上架一台**自己的 DNS 解析服务器**：解析不再交给运营商，全部设备指过来统一走加密 DNS ——智能电视、盒子、IoT、路由器这些**装不了代理客户端**的，以及**安卓「专用 DNS」**（全系统生效）。逻辑独立在 `adguard-dns.py`，与 sing-box/xray/节点互不影响，可单独卸载。

广告过滤是它**附带**的一层，不是全部。DNS 只能按**域名**拦：广告和统计放在独立域名上的（App 弹窗、网页横幅、各家 SDK 的打点域名）拦得掉；广告跟正文**同一个域名**的（视频站贴片、信息流推广）拦不掉 ——拦了那个域名正文也一起没了。所以别指望清零。挂代理的设备本来就靠订阅里的 `reject` 规则集拦广告，这边补的是「不挂代理」的场景。

```
  1 安装（装 AdGuard Home + 起服务，之后网页后台点几下完成设置）
  2 卸载（彻底移除，不动节点；若写过订阅会自动从订阅撤掉自建DNS并刷新）
  3 查看状态 / 设备怎么设置
  4 腾出 53 端口（被 systemd-resolved 占用时用）
  5 改后台端口（随机 2000-5000 / 自定义，防扫描；带回滚）
  6 把自建DNS写入订阅配置（开/关：第一次写入·再点移除，自动刷新）
  7 自检（服务/端口/证书/解析/访问控制 一次查清，只读不改）
  8 DoT 带 ClientID（签泛域名证书；要 Cloudflare 令牌，输入时明文显示）
  9 手机实测（开私人 DNS，看它连没连进来）
  10 苹果手机描述文件（iOS 一键装 DNS）
  11 节点使用私有DNS解析（1 本机DNS解析 / 2 外机DNS解析 / 3 关）
  12 改后台密码
```
> **`12 改后台密码`**：AdGuard 没有改密码的按钮能用脚本调，这里替你换：输新密码（至少 8 位，别跟用户名 / 域名一样），
> 停服务、换掉配置里那行加密后的密码、起服务，再拿新密码登一次验证；登不进去自动改回原来的密码。
> 要用 `htpasswd`（apache2-utils），没装会自动装。

> **`11 节点使用私有DNS解析`**：机场那种「节点要用它自己的 DNS 才解析得出来」。比如三台机器 1、2、3，只有 3 建了
> AdGuard：开了以后，节点地址换成只有 3 能解析的名字，公网 DNS 查不出来，订阅里看不到真实地址。
> - **名字长什么样**：
>   - 用域名装的机器：节点专用域名 `随机10位.随机6位.你的根域名`（比如 `k7xq2m4p9z.a8f3kq.example.com`），公网上不建任何记录。
>     共用证书多签一个 `*.随机6位.你的根域名` 盖住它（Cloudflare 令牌、DNS 验证，每台节点机粘一次令牌），节点地址、SNI、Host 全换成它。
>     中间隔一段随机，是因为直接签 `*.你的根域名` 会盖住节点域名（`node.example.com`），Let's Encrypt 拒签。以前开好的老名字照用。
>     **公网原来那条记录照留**：订阅、面板、伪装站、Emby 都照用。根域名上要是有 `*.根域名` 泛解析（起的名字公网查得到），不开。
>   - 用 IP 装的机器：`随机10位.internal`（`.internal` 是留给内网的后缀，公网永远查不到），只换别的机器汇总它的那份
>     （它自己的订阅地址就是它的 IP，藏了也白藏）。
> - **3 选 `1 本机DNS解析`**（要装好 AdGuard、开了加密）：屏上给出「本机 DNS 地址（给外机粘贴）」，3 自己的节点也换成节点专用域名。
>   3 汇总时把指定了它的机器的「名字 → IP」写进自己 AdGuard 的自定义规则（只动自己那一段，前后两行
>   `! xy-privdns begin / end` 圈住；IP 是拿那台的公网域名解析出来的；名字或 IP 变了才重启 AdGuard 一两秒，本机解析不走
>   AdGuard、不碍本机看片）。
> - **1、2 选 `2 外机DNS解析`**，粘贴 3 的那个地址（1、2 不用装 AdGuard，13 菜单照样进）：名字跟节点链接一起放进本机的
>   links 链接（末尾一行 `#privdns 名字 地址`，老版主机自动忽略）。3 的「聚合节点链接」里要有 1、2——3 就是靠这个拿到它们的地址。
>   屏上直说「外机已对上」还是「还没对上：原因」；对上以后再进一次本菜单，本机自己的订阅也换过去。
> - **`3 关`**：跟原来一样，节点写原来的地址。证书上的 `*.根域名`、nginx 认的节点专用域名留着；3 那边的映射再留 7 天，
>   没刷新订阅的客户端不会马上断。关了再开会换一个新名字。
> - **先问对了才换**：换名之前先去 3 问一遍，答出来的 IP 对得上才换；答不对、问不到、证书上的 `*.根域名` 丢了，
>   这一轮照写原来的地址（屏上 / 日志一行 ⚠），保证能连。1 换了 IP：3 重新汇总一次就行，名字不变，**客户端不用刷新订阅**。
> - **证书**：凡是重签共用证书的地方（装节点、15 装证书 / 修复证书、13 → 8 签泛域名和撤销）都带着 `*.根域名`，
>   要用 Cloudflare 令牌；撤销 DoT 泛域名时令牌也留着（节点专用域名续期还要用）。
> - **客户端**：mihomo 内核要 **1.19.20 及以后**（`proxy-server-nameserver-policy`，老内核会时通时不通）；sing-box 1.12 及以后
>   （出站的 `domain_resolver`）；**小火箭这份不放被藏的节点**（写法还没测出来：`claude/tools/srtest.py` 的 `pdns A / B`
>   各出一份测试订阅，手机上测）。单条分享链接照写原来的地址。
> - **被藏的机器，订阅里那条管理直连规则去掉**：开着 TUN 去 SSH 1、2 会先绕一下代理。
> - **防不住拿到整份订阅的人**：3 的 DNS 地址就写在配置里，有心人拿它去问照样问得出；3 自己的 DNS 地址、订阅地址
>   用的是它的公网域名。3 关机或 DNS 端口被封，被藏的节点就连不上（下一轮汇总自动退回原来的地址）。
> - `2 卸载` 时，本机要是在当 DNS 机，会先关掉本项、把外机的节点改回原来的地址。
> **`10 苹果手机描述文件`**：苹果没有安卓那种「专用 DNS」框，要装描述文件（iOS 14+）。选 10 印出一条链接，
> 用 **Safari** 打开 → 设置 → 已下载描述文件 → 安装。走的是 DoT（853），规则跟安卓一样：签了泛域名证书才带 ClientID（`ID.域名`）。
> 链接是 AdGuard 自带的 `/apple/dot.mobileconfig`，印出来之前先在本机试拉一遍，核对里面的主机名。
> **不给 DoH 版**：AdGuard 生成的 DoH 描述文件不写端口（我们的 DoH 在 10443），照它装连不上。
> 开着小火箭时 DNS 由小火箭接管，订阅里已经带了自建 DNS（菜单 6），不装也行。
> **`7 自检`**：**只读**，一次查清六项——① 服务在不在跑 ② 53/DoT/DoH/后台端口各由谁监听
> ③ 加密设置里的服务器名跟域名对不对、**证书还有几天到期** ④ 本机直连做**真实解析测试**
> （明文 53 / DoT / DoH 各发一次真查询，并顺带验广告有没有真拦住）⑤ **访问控制有没有限 IP**
> ⑥ 本机 ufw/firewalld 状态。最后汇总成一份「要处理的事」清单。
> **为什么要有它**：安卓「私人 DNS」是**严格模式**——填了主机名就只用这一台 DoT、**没有任何回落**，
> 它一挂手机整机所有 App 立刻解析失败（`No address associated with hostname`），
> 连节点域名都解析不出来、想靠代理自救都不行。最常见的坑是**访问控制里填了「允许的客户端」**：
> 手机从 WiFi 切到 4G 出口 IP 一变就被拒 → 整机断网。自检直接把这条标红。
> （真被锁死时的自救：手机 设置 → 网络和互联网 → 私人DNS → 改「关闭」或「自动」，解析立刻恢复。）
> **填 `ID.域名` 报「无法访问私人 DNS 服务器」，先看 Cloudflare 里 `*.域名` 那条通配记录是不是灰云（仅 DNS）**：
> 手机是先用当前网络的 DNS 把 `ID.域名` 解析成 IP、再去连那个 IP 的 853；Cloudflare **新加记录默认开着黄云（代理）**，
> 解析出来是 CF 的 IP，CF 不转发 853，手机就连不上——而自检的 DoT 是直连本机测的，照样通。所以自检 4/7 单独查这一条
> （`*.域名` 要解析到跟主域名一样的地址），菜单 8 签证书前也先查，黄云 / 没加 / 指错都直接拦下。
> **`9 手机实测`**：自检是在服务器上测的，看不见「手机 → 服务器」这一段。选 9 后把手机私人 DNS 先「关闭」再选回主机名，
> 服务器这边用 tcpdump 盯着 853（只在本机看包，不往外发任何东西；没装会先问一句再装），**每个回答都核对手机确认收到没有**，
> 一句话说清卡在哪：一个包都没到 / 只到了 TCP 握手 / 证书发了手机没收到 / 握手完了查询没到 / 回答发了手机没收到 /
> **头几个回答到了、后面的被丢**（线路先放行、后掐断：手机验证那一下过了，紧跟着的检测收不到回答，几秒后又测一次，
> 照样判「无法访问」）——这些都是半路被拦；拿到证书就断（手机不认证书）、查询到了 AdGuard 没回、全通。
> **手机的 WiFi 和流量各算一个网络、各验各的**（出口 IP 不同）：屏上每个 IP 单独一行，第一个通了也会等别的网络来完；
> 手机报「无法访问」的是哪个网络（WiFi 还是流量），就只开那一个再测一次。
> 手机开着代理、选的节点又在这台 VPS 上时，私人 DNS 的流量是节点从本机 IP 绕回来的，屏上写「本机节点转来的那路」
> （自检走 127.0.0.1，不算在内）。
> **手机开着代理时**：私人 DNS 连的是你自己的域名，订阅规则让它直连。mihomo 系客户端（Bettbox、Clash Meta 等）
> 以前直连前用「系统 DNS」解析域名，开着代理时系统 DNS 可能就是代理自己那个回假 IP 的 DNS，于是拿假 IP 去连、
> 规则模式下私人 DNS 连不上（sing-box 没这问题）。现在订阅里给自己的域名单独指定国内 DoH 解析，
> 嗅探也加了 853；**更新脚本后到「2 节点链接 / 订阅」刷新三大配置，客户端再更新订阅**才生效。
> 每行还写回了几个查询、从连上到回答几秒：**通是通、但慢到安卓等不及**（AdGuard 回一个查询超过 2 秒 → 多半上游慢；
> 回答从服务器发出到手机确认超过 1.5 秒 → **回程在丢包 / 拖延**，服务器重发了几次也写上；从连上到回答超过 4 秒 → 线路慢）
> 报 ⚠ 不报 ✔——安卓等回答只等几秒，包一个不少都到了它照样判「无法访问」。
> 开着代理（全局）能连上、直连不行，就是这种：走代理时私人 DNS 的包包在代理隧道里，运营商看不见；直连时运营商看得见这是
> 853 的 DoT，回程的回答被它丢 / 拖。服务器这边绕不过去：流量下私人 DNS 改「自动」，或者开着代理用。
> 手机填的主机名（带 ID）AdGuard 认不认，每次单独一行直说：认就是 ✔，ID 不对 / 不在白名单就是 ✗ 并给出该填的。
> 还会从握手包里读出**手机实际填的主机名**，用它在本机照安卓的检测查询（`xxxx-dnsotls-ds.metric.gstatic.com`）问一遍
> AdGuard：ClientID 填错 / 没带 / 不在白名单（AdGuard 照样回，回的是 REFUSED，光看包会当成通了）、检测域名解析不出来，
> 都直接点出来，并给出手机该填的主机名。
> **自检全绿、手机还报「无法访问私人 DNS 服务器」**：半路被拦了——云商安全组没放行 853，或者手机所在的网络
> 拦了 853（国内有的网络会拦；安卓私人 DNS 只走 853，换不了端口，服务器这边绕不过去）。WiFi 和流量各试一次，
> 一个行一个不行就是网络在拦；后台查询日志里出现过 `xxxx-dnsotls-ds.metric.gstatic.com`（安卓验证私人 DNS 发的），
> 说明有时连得上。网络拦 853 的话，私人 DNS 改「自动」，开代理时 DNS 由代理接管（订阅里的自建 DNS 走 10443，不受影响）。
> **`6 把自建DNS写入订阅配置`**：开关（循环）——把本机 AdGuard 的 DoH（`https://本机域名:DoH端口/dns-query`，
> 端口从 AdGuardHome.yaml 读、默认 10443）**动态写进订阅配置的 DNS**（用本机域名、不写死在公共模板里）。
> **三个格式都写，但机制不同**：
> - **mihomo / 小火箭**：把自建 DoH 放 DNS 列表**最前当主用、原有留兜底**——AdGuard 没通会**自动回落**到原 DNS，
>   不会断解析。mihomo 写两处：`nameserver`（默认解析）+ `global-dns` 锚点（`nameserver-policy` 里所有走代理的
>   域名组 `*global-dns` 共用它，改锚点一行 17 个组全带上）；**`cn-dns` 组不动**——国内域名该走国内解析拿就近 CDN，
>   用境外自建 DNS 反而慢。
> - **sing-box**：把**配置自己声明的兜底 DNS** 那台换成自建 DoH（`detour` 走**直连**、
>   `domain_resolver` 用模板里的 `bootstrap` 解析域名本身）。国内 `local`、国外 `remote`、`fakeip`
>   **都不动**：兜底只接没被任何规则分到的查询——作者模板里 A/AAAA 先给 fakeip（直连的再用 `local`
>   解真实 IP，走代理的交给服务端）、局域网走 `local`、「全局」走 `remote`，落到兜底的只剩 MX / TXT
>   这类零头。所以 AdGuard 挂了，**日常解析不受影响**，只是这部分零头查不到。
>   - 为什么改兜底那台：`local` 是国内解析（换掉就拿不到就近 CDN，同 mihomo 那边 `cn-dns` 不动），
>     `remote` 是「全局」模式专用；兜底那台没被任何规则命中时才用，动它副作用最小。
>   - **怎么认出是哪一台**：读 `dns.final` 的值——那是配置自己写明「没被规则命中时用谁」的 tag。
>     作者模板里它恰好叫 `final`，**自定义模板可以叫别的名**（比如 `dns.final: "fallback"`），
>     照样认得出。**不按地址锚定**：按 `8.8.8.8` 匹配的话，谁把兜底换成 `9.9.9.9` 就静默失效了。
>     所以只要是那台兜底，不管它原来指谁（`8.8.8.8` / `9.9.9.9` / 别的 DoH）都会被顶掉——
>     这正是「写入自建 DNS」的本意。
>   - **只清寻址字段**（`type`/`server`/`server_port`/`path`/`tls`/`headers`/`detour` …），
>     其余原样保留。`tls.server_name` 必须清掉：留着 `dns.google` 就会拿它当 SNI 去连你自己的域名；
>     而自定义模板里加的 `client_subnet` 之类不该被抹掉。
>   - **找不到就明确报警**（`dns.final` 指向的 tag 不存在、或模板压根没有 `dns.servers`），
>     不静默跳过——用自定义模板的人得知道 sing-box 这份没写进去。
>
> 第一次点写入、再点问是否移除，
> 执行后自动刷新订阅（不换 token），客户端重拉一次即生效。前提：AdGuard 已开加密(DoH)、防火墙放行 DoH 端口。
> **卸载联动**：`2 卸载` 时如果之前用过本项写入订阅，会**自动把自建 DoH 从订阅里撤掉并刷新**（不换 token），避免订阅里留着指向已卸载 AGH 的死 DoH；客户端重拉即恢复原 DNS（mihomo/小火箭本就带回落，撤不撤都不会断解析，撤掉更干净）。全量卸载（主菜单 `17`）则整条订阅一起删，无需刷新。
> **`5 改后台端口`**：把网页后台的 3000 改成随机 2000-5000（或自定义），避免固定端口被批量扫描。
> 只改后台管理端口——**DNS 端口是协议固定的动不了**（53 明文、853 DoT/安卓专用DNS、10443 DoH）。
> 带校验回滚：改完 AGH 没在新端口正常起来就自动回滚，不会把你锁在后台外面。改完记得防火墙放行新端口、关掉旧的。

- **自建 DNS 用自己的域名、自己的证书**（10/29 起新装）：菜单 1 安装时先问一个只给 DNS 用的域名（比如 `dns.你的域名`），
  查好 `域名`、`*.域名` 两条 A 记录（仅 DNS）指向本机，再用 Cloudflare 令牌单独签一张 `域名 + *.域名` 的证书，放在
  `/etc/ssl/agh/`，自己续期。像 Emby 一样先认出节点域名，回车默认 `dns.节点的根域名`（同一个令牌管得到）；
  不能填节点域名本身（acme.sh 按名字存记录，会把节点那条顶掉）。跟节点、Emby 完全分开：节点证书不再替它背 `*.节点域名`，节点重装 / 换域名都不用令牌（开了
  私有解析的除外，见 11）。**换域名 = 卸了重装**。令牌签不出来多半是没管到这个域名的区域：去 CF 编辑那个令牌把区域加上，
  别新建一个顶掉（acme.sh 只存一个，顶掉以后别的证书续期会失败）。老装法（跟节点共用证书）照旧能用，想分开就卸了重装。
- **一键装好起服务**：菜单 1 用 AdGuard Home 官方脚本装到 `/opt/AdGuardHome` 并注册服务。AdGuard Home 是**网页后台管理**的软件。装完**在终端里直接问你后台用户名、密码**（用户名回车 = 自建 DNS 自己的域名；密码至少 8 位，明着输、输一遍），脚本替你走完网页向导，后台**直接用随机端口**（2000-5000），屏上给出后台地址（云防火墙放行这个端口）。密码那里输 `n`，或者自动设置没成，就照旧打开 `http://VPS_IP:3000` 按网页向导设（**广告过滤默认就开**）。
- **设备怎么用**：
  - **电视/盒子/IoT/路由器**：DNS 填 **VPS 的 IP**（明文，需放行 `53` UDP/TCP）。
  - **安卓手机「专用 DNS」（全系统加密，推荐）**：网页后台 → 设置 → 加密设置，启用、服务器名填**你的域名**、
    证书指到自建 DNS 自己那张（`/etc/ssl/agh/agh.crt` + `agh.key`；老装法是 `/etc/ssl/sb/acme.crt` + `.key`，「3 使用方法」里会写明该填哪个）、
    DoT 端口 `853`、HTTPS/DoH 端口填 `10443`（不占 443）；然后手机 设置→网络→专用DNS→ 填**自建 DNS 的域名**，全系统 App 的解析都走这台。
- **加密走 DoT(853)**：DoH 需要 443（被 reality/nginx 占了）故不用；DoT 走 853 独立端口，不影响现有节点。**需要域名 + 真证书**（安卓专用 DNS 才验得过）。
- **端口 53 冲突**：常被 `systemd-resolved` 占用——加密 DoT(853) 不受影响；要走明文 53 就用菜单 `4 腾出53端口`（关掉 resolved 的 53 桩监听，可逆）。
- **安全**：公网 DNS 有被拿去做 DDoS 放大的风险，AdGuard Home 默认带每客户端限速；优先用 DoT、别裸奔明文 53。
- **进后台优先用域名 HTTPS**：开了加密后，AGH 后台**同时挂在 `https://你的域名:10443/`**（和 DoH 同一个 HTTPS 端口——根路径 `/` 是后台、`/dns-query` 是 DoH），登录密码全程加密。别再用 `http://IP:端口` 明文登录（密码会明文过网）。AGH 本身**不支持 URL 加 token/密令路径**，后台靠「随机端口 + 账号密码 + HTTPS」三层防护即可；状态(3)/自检(7)/改端口(5) 检测到开了加密都会把这条 HTTPS 地址显示出来、并把明文入口标注出来。
- 主菜单 `19 卸载`（整体卸载）会**一并撤掉 AdGuard Home**（它的 DoT 依赖 acme 证书，证书随整体卸载删除）。
