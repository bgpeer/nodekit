# 附：Nginx 是共用件（谁先需要谁装，都走同一个源）

真正用到 nginx 的有三处：**节点**（伪装站 80/443、SNI 分流的 `stream`+`ssl_preread`）、
**Emby 那套**（443 反代）、AdGuard（只 reload，共用证书）。所以它不归任何一边私有。

做法是只留一个入口 —— `net-optimize.py --nginx-ensure`：配 nginx.org 官方源
（Pin=1001）、没装就装上、挂每月 1 号 03:10 的自动升级。

| 你的顺序 | 发生什么 |
|---|---|
| 先装节点（需要 nginx） | 节点调这个入口把 nginx 装上，源和月度升级一并配好 |
| 先跑「12 网络优化」再装节点 | 源已经在，节点装 nginx 直接拿官方版本 |
| 只跑「12 网络优化」，没人要 nginx | **只配源，不主动安装**，也不挂 cron |

最后一行是有意的：点「网络优化」是想调内核参数，不该因此多出一个监听 80 的
web 服务。源配好不装任何东西、不起任何服务，纯粹是为了后面真要装时能拿到官方版本。
装失败也不会挂 cron —— 挂了只是每月在没人看的时候重试安装。

> nginx 版本是有实际影响的：1.25.1 起 `listen ... http2` 被弃用、改用独立的
> `http2 on;`，而 `http2 on;` 在旧版上是未知指令、会让 `nginx -t` 直接失败。
> Debian 12 出厂是 1.22.1，走不到那条路。
